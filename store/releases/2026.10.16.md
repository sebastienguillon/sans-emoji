Prepared on October 16, 2026. This release changes only the desktop Firefox minimum version since `v2026.10.15`, to clear the warning in Mozilla's validation report for the 2026.10.15 package. Preparing and tagging the release does not upload it to a store, request signing, or publish the website.

## Public version notes

### English

Desktop Firefox 142 or later is now required, up from 140. Mozilla no longer updates Firefox 140 ESR or 141. Otherwise, the extension works exactly as in 2026.10.15.

Known limitations: an editor that rejects synthetic Escape may still intercept Enter or Tab; simultaneous autocomplete menus are not independently scoped while a colon query exists. An error panel without emoji items can appear after its query disappears. Atlassian markup changes can affect support, and custom company domains remain outside scope.

### Français

Firefox 142 ou une version ultérieure est désormais requis sur ordinateur, contre 140 auparavant. Mozilla ne met plus à jour Firefox 140 ESR ni Firefox 141. Le fonctionnement de l’extension est par ailleurs identique à la version 2026.10.15.

Limites connues : un éditeur qui refuse les événements Échap synthétiques peut encore intercepter Entrée ou Tabulation ; les menus de saisie simultanés ne sont pas gérés indépendamment tant qu’une recherche d’emoji est active. Un panneau d’erreur sans emoji peut apparaître après la disparition de son champ de recherche. Les changements du balisage Atlassian peuvent affecter la compatibilité et les domaines personnalisés des entreprises restent hors périmètre.

## Validation and remaining checks

Use the [versioned release notes](../../release-notes/2026.10.16.md#validation) for the checks actually completed against this release.

- Upload the package to Mozilla Add-ons and confirm that its validation report no longer shows the Android minimum-version warning. Local validation passed with no warnings, but AMO may run a newer linter.
- The signed-in editor matrix recorded as pending for 2026.10.15 is still pending: `Bonjour : suite`, both non-breaking-space variants, Enter/Tab, undo/redo, mentions, slash commands, and the toolbar picker. The extension code is unchanged, so a check of either build covers both.
- Browser fixtures use the actual unpacked extension in Chromium and inject the compiled script and stylesheet in Firefox. They do not verify Firefox add-on installation or signing. A real Firefox add-on run and checks on the Chrome 120 and Firefox 142 minimum versions remain pending. Desktop Firefox 142+ is required; Android distribution is not enabled.

## Submission steps

1. Complete the remaining checks above and record their results in the versioned release notes. If packaged source files change, run `pnpm package` again and regenerate the archive checksums.
2. In Mozilla Add-ons, upload `dist/sans-emoji.zip` as new version `2026.10.16`. AMO does not accept a version number that was already uploaded, so a corrected 2026.10.15 package cannot replace the earlier one. Read the full validation report before submission.
3. Upload `dist/sans-emoji-sources.zip` separately and enter the public version notes above. Complete the [private reviewer-note template](../submission.md#private-reviewer-note-template), which now states the Firefox 142 minimum, with working dedicated test credentials, a supported HTTPS sample editor, and exact login steps. Keep those credentials out of public notes and both archives.
4. Optionally, upload the same extension ZIP to the Chrome Web Store as version `2026.10.16`.
5. Submit after the remaining review items are complete. Record submission, signing, and approval status separately. No store submission or website deployment is recorded by this handoff.
