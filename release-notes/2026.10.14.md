# Sans Emoji 2026.10.14

**Abandoned before tagging.** The planned release was superseded by [2026.10.15](2026.10.15.md), which includes these changes and the subsequent performance and Firefox fixes. The record below describes the October 14 preparation and its validation, not a published release or validation of the final October 15 build.

Prepared for publication on October 14, 2026. Changes since `v2026.10.10`. Store submission and approval are separate steps.

## Fixes

- Prevent hidden emoji suggestions from briefly expanding the page or a scroll container and causing a scrollbar or layout jump while they are created and removed.
- Keep modern emoji popups suppressed when they appear after their inline query disappears or remain mounted during cancellation. The typed colon stays visible, and legacy popup cancellation remains supported.

## Submission materials and documentation

- Include English and French fixture screenshots, Chrome promotional images, store icons, editable sources, and capture provenance. The screenshots are clearly labeled local editor demonstrations, not live Atlassian product screenshots.
- Expand Firefox submission guidance with public version notes, dedicated reviewer test access, private reviewer instructions, and source reproduction steps.
- Link the related Jira and Confluence feature requests from the README and public website source. These documentation changes do not establish a new website deployment.
- Record the no-flash and no-layout-shift requirements in the README and contributor instructions, together with the suppression approaches that fell short, the legacy layout constraint, and unmeasured performance considerations. Future optimizations must preserve the achieved visual behavior.

## Validation

- The versioned 2026.10.14 build passed 74 unit tests with 100% statement, branch, function, and line coverage, plus all 58 Chromium/Firefox browser fixture checks. During development, eight overflow cases reproduced the original bug, and four delayed-removal cases exposed the query-selector timing gap before its fix.
- A signed-in Jira description editor in Zen was checked using the final stylesheet in a temporary style element. The old popup expanded document height from 1,166 px to 1,554 px; the fix kept it at 1,166 px during the observed popup states, including after the query disappeared. The popup was subsequently removed. The draft text and image were restored without saving the issue.
- With Node.js 24.18.0 and the pinned pnpm 12.10.1, `pnpm install --frozen-lockfile` and `pnpm package` passed. Packaging checked all three TypeScript environments, lint, unit coverage, a clean build, and extension linting with zero errors or actionable warnings. The desktop-only Android minimum-version warning was explicitly skipped. `pnpm exec playwright test` passed against that versioned build.
- Regenerated all eight versioned store images with the unpacked 2026.10.14 build in Chromium 156.0.8078.4. The capture assertions passed, and the images were visually reviewed and checked for dimensions, color mode, and embedded provenance. Historical 2026.10.10 images and their capture manifest were preserved.
- The public homepage, privacy policy, and support page each returned HTTP 200 over HTTPS without authentication on October 14, 2026.

## Known limitations and submission checks

- The live check covered the Jira popup layout fix. The broader manual matrix, including non-breaking-space variants, Enter/Tab, undo/redo, mentions, slash commands, and the toolbar picker, was not repeated in a signed-in editor for this release. Bitbucket and Confluence were not checked live.
- Chromium fixtures load the unpacked extension; Firefox fixtures inject the compiled script and stylesheet. They do not verify Firefox add-on installation or signing. Desktop Firefox 140+ is required; Android distribution is not enabled.
- An editor that ignores synthetic Escape may retain an invisible autocomplete state that consumes Enter or Tab. Internal Atlassian markup changes can affect support. Custom domains and unrelated frame URLs remain outside scope; simultaneous modern menus are not independently scoped while a colon query exists.
- Reviewers need working dedicated test credentials and an editable sample page, supplied privately through the store dashboard. Credentials are not included in the repository or archives.
- The extension archive is unsigned. Preparing these files does not publish a store update or request Mozilla signing.
