# Sans Emoji 2026.10.10

Initial release.

These historical notes describe the initial version's behavior and validation. See [unreleased changes](unreleased.md) for the subsequent popup suppression and shared-build changes.

- Dismiss colon-triggered emoji autocomplete on HTTPS Atlassian and Bitbucket domains, including their subdomains.
- Preserve typed text and French punctuation spacing, including non-breaking spaces.
- Leave mentions, slash commands, and the manual emoji picker available.
- Provide Chrome and Firefox builds with the neutral-face icon and red diagonal slash.
- Use no telemetry, storage, or network requests.

## Development and distribution

- Strict TypeScript 7 and pnpm 12 tooling.
- Separate `pnpm build` for local browser loading and `pnpm package` for distribution.
- Include matching source code and build instructions for Mozilla review.
- Release as open source under the MIT License, included in local builds and all distribution archives.

## Validation and limitations

- Typechecking, linting, and 68 unit tests pass with 100% statement, branch, function, and line coverage for runtime and tooling code.
- Packaging tests rebuild extracted sources and compare shipped files and archives across checkout paths.
- Tests use representative editor fixtures; compatibility with a signed-in Atlassian tenant has not been verified.
- The popup may appear briefly before dismissal. If an editor ignores synthetic Escape or changes its markup, the extension stops retrying and leaves the menu visible.
- Firefox requires version 140+ and Mozilla signing for permanent installation in standard releases.
