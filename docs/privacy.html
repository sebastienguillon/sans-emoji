Where the extension runs

Sans Emoji runs only on HTTPS atlassian.net, atlassian.com and bitbucket.org pages, including their subdomains and frames whose own URLs match. It does not run on other websites. All executable extension code is included in the installed package.

What it reads and why

  • Editor and suggestion-panel structure. The extension checks page elements and their attributes to identify colon-triggered emoji autocomplete and hide its suggestion panel.
  • Focus, typing and composition events. It observes which field is active, when input changes and when input method editor composition starts or ends. This lets it cancel autocomplete in the active editor and wait until composition has finished.
  • Caret position and editor text. In supported legacy editors, it reads text before the caret to check for a colon query. This can include text from your draft. The check happens locally, and the extension does not save or transmit that text.
  • The page’s protocol and hostname. These are checked to limit operation to the supported HTTPS domains. The extension does not create a browsing-history log.

Cancellation sends a synthetic Escape key event to the editor. The editor handles its own text and selection; Sans Emoji does not submit your writing.

Storage and retention

The extension uses no local or sync storage, cookies, database or saved files. It keeps temporary references to candidate page elements and retry counts in memory while a page is open. These are not an activity log; navigating away or closing the tab clears that page’s extension state.

What it sends

Sans Emoji makes no network requests and has no developer server, analytics, telemetry or remote code. It does not send editor text, page content or browsing activity to the developer or any third party.

The Atlassian website continues to process and save what you type according to its own behavior and policies. Installing Sans Emoji does not prevent that website from accessing your writing.

Permissions

Access to the supported Atlassian and Bitbucket pages allows the extension to inspect editor elements, hide recognized suggestions and send the cancellation event. It does not request additional extension API permissions, including storage, tabs, cookies, webRequest, downloads or history access.

Your choices

You can disable or remove Sans Emoji in your browser’s extension manager. Refresh open Atlassian tabs afterward so the previously loaded script and stylesheet are removed. There is no retained extension data to delete.

Limited use

Sans Emoji’s use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Editor content is used only to provide the stated autocomplete-suppression feature. It is not sold, used for advertising, transferred for unrelated purposes, or used to determine creditworthiness or lending eligibility. The developer does not receive or review users’ editor content through the extension.

This website and support

This website uses no analytics scripts, third-party fonts, embedded trackers or tracking cookies. When served on GitHub Pages, GitHub processes visitor information under the GitHub Privacy Statement, including IP addresses for security purposes. This website hosting is separate from the extension’s operation.

If you email the developer, the address and information you choose to send are used to respond to your request and are handled by the email providers involved. Please send only what is needed to explain the issue. Do not include passwords, session tokens, confidential issue text or private project details. You can contact the developer to request deletion of support correspondence.
